TZ / 01

保护区边缘的度假村：零外网流量看电视

坦桑尼亚 · 野奢度假村
BACKGROUND / 背景

位于野生动物保护区边缘，住客是来狩猎与观星的客人。位置偏远，本地互联网带宽小、按流量计费，雷雨季还常停电。

ISSUE / 难点
  • 外网不可靠：直播如果依赖公网，客人一多就卡
  • 维护人员有限：现场没有专职 IT，设备要好装好修
  • 弱电品类多：电视、监控、门锁、门禁都要有人兜
SOLUTION / 方案
  • 整套 IPTV 跑在酒店局域网内，直播与欢迎页不消耗外网流量
  • 服务器、交换机、机顶盒在工厂预配置，现场插上即用
  • 电视、CCTV、智能门锁与门禁由同一家供应商供货
  • 售后以总部远程接管为主，减少现场出勤
RESULT / 结果

系统在无外网条件下稳定运行，客人可看直播与酒店服务；运维由总部远程处理，现场只需换机备件。

ME / 02

1,368 家连锁酒店：从同轴升级到 IPTV

中东与北非 · 连锁酒店
BACKGROUND / 背景

一个连锁品牌的多家物业仍在用同轴有线电视，频道少、无法做点播与欢迎页，改造预算又受限于每店房量不同。

ISSUE / 难点
  • 房量从几十间到数百间不等，配置要能伸缩
  • 既有同轴与网线混用，改造不能停业
  • 连锁总部要统一频道表与界面
SOLUTION / 方案
  • 按房量分档配置：一体机 / 模块化服务器两种前端
  • 保留部分原有线路，只替换机房侧与客房末端
  • 频道表与界面模板由总部统一下发
RESULT / 结果

完成 1,368 家物业的同轴到 IPTV 升级，客人可看点播与酒店服务，总部可统一管理频道内容。

DJ / 03

吉布提：政府公寓与养老院两处集中前端

吉布提 · 政府公寓 / 养老院
BACKGROUND / 背景

两处物业分别服务军方与政府家庭、以及退休官员，需求相同：稳定的本地电视与信息服务，不依赖外网。

ISSUE / 难点
  • 多栋楼分散，前端只能集中在一处
  • 住户年龄偏大，遥控器必须简单
  • 本地维护能力弱
SOLUTION / 方案
  • 集中式前端 + 楼栋光纤延伸，客房端只放机顶盒
  • 酒店模式锁定频道表，一个遥控器完成开关机与换台
  • 远程售后 + 备件先行
RESULT / 结果

两处物业共用同一套前端架构，后期扩容只增加机顶盒与接入交换机。

ME / 04

120 家集成商背后的 IPTV 技术线

中东 · 系统集成商群体
BACKGROUND / 背景

当地系统集成商拿酒店项目时，弱电里最不懂的是 IPTV：要报价、要方案、要能跟业主解释清楚。

ISSUE / 难点
  • 集成商没有 IPTV 工程师，方案与报价都靠猜
  • 业主要求英文方案与本地化支持
  • 项目金额跨度大（2 千到 80 万美元）
SOLUTION / 方案
  • 为集成商提供可复用的方案模板与配置清单
  • 技术答疑直接对接工程师，不经过销售转达
  • 按项目规模分档供货：小项目一体机，大项目模块化 + 双机
RESULT / 结果

累计服务 120 家集成商，单项目金额从 2 千美元提升到 2 万–80 万美元区间，其中包含一个约 346 万美元的医院整体方案（医疗家具 + IPTV + 广播）。

ET / 05

亚的斯亚贝巴：DVB-T2 前端 + 双流冗余

埃塞俄比亚 · 城市酒店
BACKGROUND / 背景

当地地面数字电视（DVB-T2）覆盖较全，酒店希望以地面信号为主源，同时保证单点故障不停播。

ISSUE / 难点
  • 地面信号受天气与地形影响
  • 频道表要覆盖本地台与体育频道
  • 机房只有一个小机柜
SOLUTION / 方案
  • DVB-T2 前端接收 + 双路冗余输出
  • 一台模块化服务器完成协议转换与业务分发
  • 小机柜内上架，走既有弱电
RESULT / 结果

主备两路信号自动切换，单路故障时客人几乎无感；小机房内完成整套前端。
