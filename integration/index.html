09 — INTEGRATION

酒店弱电系统

八类系统里，只有电视每间房都有——所以从它切进去。

电视与 IPTV、客控、门锁取电、PMS、WiFi AP、IP 电话、CCTV、信息发布。它们共用弱电井、桥架和同一个决策人。

系统优先级在酒店里干什么与 IPTV 的联动点
客房电视 / 酒店专用电视 重点 客人唯一直接面对的屏幕 与 IPTV 靠 HDMI 连接；开机源、音量上限、酒店模式都要在电视侧锁定
客控系统（灯光 / 空调 / 场景） 二级 与电视共用同一块墙面与同一个控制面板 电视界面可作为客控入口；客控网关与 IPTV 服务器可在后台对接场景与状态
门锁与取电开关 二级 插卡取电、开门记录 取电开关通电后电视与机顶盒随房间启用；门锁记录可与欢迎词联动（按项目实现）
PMS 酒店管理系统 二级 房态、账单、退房 IPTV 与 PMS 对接后，电视上可查账单、一键退房，欢迎词带客人姓名
WiFi AP 二级 客房上网 与 IPTV 常在同一张接入网：同一台 PoE 交换机供电，VLAN 分开承载
IP 电话 二级 客房电话与前台 同样走 PoE 交换机；与电视同一套弱电点位，省桥架与人工
CCTV 监控 二级 公共区域与出入口 可与 IPTV 同网承载（需带宽与 VLAN 隔离）；部分项目要求客房电视能看指定监控画面
电子门牌 / 信息发布 三级 走廊屏、宴会厅屏 与 IPTV 共用内容管理与排播思路，按项目是否并入同一系统

优先级：电视与 IPTV 是同一张清单、同一个决策人、同一个房间，资源优先给它；其余品类做联动说明，不单独招商。

01

为什么从电视切进去

酒店弱电的采购往往由一件事触发：客房电视要么没信号、要么太旧、要么客人抱怨。电视与 IPTV 是最先被拿出来讨论的，也是唯一每间房都要装的东西。谈完电视，弱电其他部分才有机会。

看酒店专用电视 按房量看配置
SCOPE / 我们做哪些

电视与 IPTV 是我们自己的产品线；客控、门锁、PMS 我们做对接与配置，不做生产。项目上如果客户指定品牌，我们负责把它跟 IPTV 接起来，不抢品类。

一张图：五类系统怎么进客房

机房汇入 → 走廊机柜分光 → 客房五条线分开落地。这张图画的是物理路径，不是产品清单。

01 机房

卫星、地面、有线、HDMI 信号在这里统一变成 IP；前端服务器、三层交换机、OLT 都在这一段。

02 走廊机柜

楼栋与楼层各一级分光，一根光纤进楼层，ONU 再分出电视、网络、电话、广播、客控五条线。

03 客房

电视与机顶盒、网络、电话、广播、客控是并列的五条线；客控不串在电视前面，坏一套不影响另一套。
