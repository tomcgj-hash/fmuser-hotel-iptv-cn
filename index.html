03

为什么找我们：五条，能查证的

不讲“行业领先”“实力雄厚”。每一条都能对应到具体国家、具体认证、具体售后动作。

01

国外项目是主场，不是副业

18 年只做广电与酒店IPTV 前端，30 多个国家、1,000 多家酒店客房系统。现场安装由我们自己的工程师带队。

30+ 国家坦桑尼亚 / 吉布提 / 埃塞俄比亚 / 中东
02

国外客户要的定制功能

欢迎页、滚动通知、酒店介绍、餐饮服务、DRM 与 Netflix / YouTube、酒店模式锁定，按目的地与授权范围配置。

按项目配置不做“全球通用”的空承诺
03

CE 认证，投标与清关可用

整机 CE 认证，证书与编号可查；投标文件、清关资料、目的国认证排期可随货提供。

证书可查文件随货或按项目提供
04

IPTV 不是快销品

这套系统要用五到十年。安装、调试、2 年质保、备件常备、远程与到场支持——买完之后才是服务的开始。

2 年质保备件按 3–5% 常备
05

可与酒店 PMS 打通

与 PMS（含 OPERA）对接后，房态、账单、退房、欢迎词可直接打通到电视界面。字段按项目评估，只承诺验证过的部分。

按项目验证房态 / 账单 / 退房 / 欢迎词
04

系统图：信号从哪里来，到哪里去

四段式：信号源 → 前端机房 → 网络分发 → 客房终端。虚线为信号流，实线框为责任边界。

虚线 = 信号流（UDP 组播 / HLS） 实线框 = 我们交付 斜线填充 = 软件与授权
