02 — SYSTEM

酒店IPTV系统

一套系统要跑五到十年，所以它在没网、断电、没人管的时候也得能用。

酒店IPTV系统由四层组成：信号源、前端机房、网络分发、客房终端。本篇逐层写清每层包含什么设备、我们交付到哪一步、以及这一层最容易出问题的地方——看完你能判断自己要买的是哪一种系统。

先用 12 分钟看懂：一套酒店IPTV 系统长什么样

我们自己的设备在一张桌子上从卫星天线一路接到客房电视，边接边讲。英文旁白，画面里有完整接线路径。

这段视频回答三件事

  • 信号怎么变成 IP：卫星天线 → 接收机 → 编码 → 网关，桌上每一步都能看到实物。
  • 客房那端看到什么：机顶盒开机 → 欢迎页 → 频道表，不是安卓桌面。
  • 为什么酒店断网还能看：整套跑在局域网，外网只做售后与片库更新。

01

三种节目源，选哪条路

这一层决定设备清单，也决定长期成本。同一个酒店，自收卫星与运营商 IPTV 的前端配置可以差一倍。

OPTION A

自收卫星（DTH）

适用
当地卫星上有免费或可授权的频道，且屋顶可架天线
需要的设备
天线 + LNB + 接收机（免费用 FTA，加密节目要 CAM/CI）
成本结构
一次性投入高，长期无月费
OPTION B

买运营商 IPTV

适用
当地有酒店专线 IPTV 套餐，房间数与月费谈得下来
需要的设备
IP 网关 / 服务器做协议转换与分发，通常不需要天线
成本结构
设备投入低，按月付费
OPTION C

有线电视同轴（CATV）

适用
楼里已有同轴并仍在服务，改造要保住老电视
需要的设备
接收机（按当地制式 DVB-C / ISDB-T / ATSC）+ 编码或网关
成本结构
改造成本可控，节目质量取决于原信号

系统层面最常被问的四件事

01 一套酒店IPTV系统最少要哪些设备？

四件套：信号源设备（接收机或编码器）、前端服务器（FBE700 / FBE900 / FBE80x）、交换机、客房端（机顶盒或安卓电视装 APK）。房间数少、节目源已在 IP 上的项目，可以只用一台一体机加交换机和机顶盒。

02 没有外网能用吗？

能。整套系统跑在酒店自己的局域网里，直播、点播、欢迎页、酒店服务都不依赖公网。需要外网的是远程售后与云端片库更新，可按项目选择是否启用。

03 老酒店同轴线要不要全部换掉？

要看。如果要把模拟有线换成 IPTV，客房到弱电井的网线是必须的；如果只在机房侧做转换、客房保留电视与同轴，则走有线电视前端的做法。两种方案我们都能给，区别是客房电视是否配机顶盒。

04 一台服务器能带多少间房？

按官方标称与实测数据说话：FBE803 一体机最多 800 台终端、约 80 路 2 Mbps 节目可支撑约 600 台电视；FBE700 / FBE900 的并发与路数按所选功能卡与码率实测确定。100 间客房的常规配置一台 FBE700 足够；200 间以上建议 FBE900 或双机热备。
